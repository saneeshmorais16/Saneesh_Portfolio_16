## Run Locally

Open `index.html` directly in a browser, or serve the folder with a simple static server.

```bash
python -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000
```

## Deploy With GitHub Pages

This repository includes a GitHub Pages workflow in `.github/workflows/static.yml`. After changes are merged into `main`, GitHub Pages should redeploy the static site automatically.
